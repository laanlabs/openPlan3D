# Demand-driven 2D drawing

September 8, 2026 · [Issue #84](https://github.com/laanlabs/openPlan3D/issues/84)
· [PR #85](https://github.com/laanlabs/openPlan3D/pull/85)

## Behavior

The 2D editor polled a dirty flag on every animation frame. Measure, Dimension,
placement and drag modes also set that flag during drawing, even without another
input. The editor now coalesces invalidations into a requested frame and leaves
no frame queued once changes have rendered. Invalidation raised during drawing
is retained for the next frame; stopping cancels pending work and rejects late
image/texture callbacks.

Store subscriptions and mouse/touch handlers still request drawing. Local camera,
grid/ruler, label/dimension, minimap, Shift and drag-preview changes now request
frames too, so they do not need an unrelated pointer movement to appear. Loading
a tracing image wakes the canvas; a late image from another floor or a closed
component cannot replace the current underlay. Repeated floor edits reuse the
current image source instead of launching another decode while it is loading.

## Native measurements

The deterministic medium furnished home has two floors and 108 furniture items;
its active first floor has 9 rooms, 24 walls, 12 doors, 6 windows and 54 objects.
The deployed baseline is main `69bb2e1`, version `1788856326076`. The comparison is
a local production build of implementation commit `a545f1b`. A later binding
follow-up explicitly makes the minimap canvas reactive; native hide/show and
minimap navigation were rechecked on that build after reloading.

[Sanitized numerical measurements](2026-09-08-2d-idle-metrics.json) use the same
10–35 second range from each recording, with no input during those ranges:

| Mode | Animation callbacks, before → after | Frame requests, before → after | Mean page CPU sample, before → after |
| --- | ---: | ---: | ---: |
| Select | 1,500 → 0 | 1,500 → 0 | 1.68% → 0% |
| Measure, before placing points | 1,500 → 0 | 1,500 → 0 | 23.762% → 0.002% |

Inspector's rendering-frame records also fall from 1,500 to zero, but include
callbacks that return without canvas drawing; they do not establish 1,500
Select-mode repaints. CI separately observes actual 2D `clearRect` calls. Baseline
order was an initial 13-second Select sample (excluded here), Measure, then a full
Select sample; updated order was Select then Measure. Mean page memory was
285.61/109.22 MB for Select and 267.22/110.56 MB for Measure. The different warm-up,
prior interaction and garbage-collection histories prevent a memory-saving claim.

Device: M4 Max Mac Studio (Mac16,9), 14 CPU cores, 36 GB RAM, macOS 26.2 build
25C56, Safari 26.2. Inspector is docked below: document 1,324 × 350 CSS pixels,
2D canvas 1,068 × 302, DPR 1. Instruments: Network Requests, Layout & Rendering,
JavaScript & Events, CPU and Memory. Screenshots, Media & Animations and
JavaScript Allocations are off. Raw traces remain outside git; the numeric-only
report uses `tooling/safari-timeline.mjs`.

These single samples use different origins/loading histories with other desktop
apps open and profiling overhead. CPU samples are page samples, not whole-device
power or battery measurements. Memory figures do not isolate retained allocations.
No active-editing frame-time budget or physical-phone result is established.

## Verification

Local type checking passes with zero errors and 22 remaining Svelte warnings;
628 unit tests and the production build pass. Scheduler regressions cover burst
coalescing, frame ID zero, in-draw invalidation, teardown and late callbacks.
New CI workflows observe actual canvas clears and browser RAF requests without
production debug hooks. They cover display toggles, camera/minimap, measurement
and wall previews, Shift, column placement, undo/redo, floors, resize, 3D/2D
remounts, reordered image completions and synthetic phone-width touch pinch/pan.
The suite now has 75 workflows per engine (225 across Chromium, Firefox and
WebKit), plus six furnished-home benchmarks. Final browser CI and deployment
results are reported on PR #85.

Native Safari verified measurement placement, Select/Measure transitions, grid
and ruler toggles, zoom/fit, undo/redo, Level 1/2 switching, 3D rendering, reload,
and minimap hide/show/navigation. Inspector instruments and the developer-features
toggle were restored afterward. Making the minimap binding reactive removes one
existing Svelte warning.

No Firebase writes, uploads, new assets or dependencies are added. Physical
phones, active editing/navigation measurements, native distribution and the #30
release/cost gates remain outstanding.
